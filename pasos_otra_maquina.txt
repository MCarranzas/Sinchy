  2.2 TRAMPAS DE php.ini EN PHP 8.4 WINDOWS (aplicadas en la original)
      - Una sola linea `extension_dir = "ext"` (la de por defecto

        arranca con "Unable to load dynamic library" x4.

        `extension = opcache`.

  2.3 VC++ REDISTRIBUTABLE
      Los builds "vs17" de PHP 8.4 Windows exigen VC++ 2015-2022 x64.
      Verificar con (Get-ItemProperty, NO Get-ChildItem - ver paso [22] de
      pasos.txt, ese error genero un bloqueo inexistente):
        Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\VisualStudio\14.0\VC\Runtimes\x64"
      Debe devolver Installed = 1, Version >= v14.x

  2.4 VERIFICACION DE PHP

################################################################################
 # 3. PATH EN WINDOWS - EL ORDEN MANDA
################################################################################

  3.1 REGLA: Windows concatena PATH de SISTEMA + PATH de USUARIO, y el de
      sistema va PRIMERO. Anteponer algo en el PATH de USUARIO NO SIRVE si
      C:\xampp\php esta en el de sistema: XAMPP gana siempre (paso [39] de
      pasos.txt).

  3.2 Orden CORRECTO del PATH de SISTEMA (Machine), al inicio:
        C:\tools\php84
        C:\Program Files\PostgreSQL\17\bin
        ... resto ...
        C:\xampp\php            (al final, si XAMPP sigue instalado)

      Script (elevar a Administrador):
        $sys = [Environment]::GetEnvironmentVariable('Path','Machine')
        [Environment]::SetEnvironmentVariable(
            'Path', "C:\tools\php84;C:\Program Files\PostgreSQL\17\bin;$sys",
            'Machine')
      RESPALDAR el PATH original ANTES de tocarlo.

  3.3 TRAMPA DE LA SESION: el PATH del REGISTRO no afecta a las terminales ya
      abiertas. Tras modificarlo: abrir terminal NUEVA, o refrescar en la
      misma sesion:
        $env:Path = [Environment]::GetEnvironmentVariable('Path','Machine')
                  + ';' + [Environment]::GetEnvironmentVariable('Path','User')

  3.4 VERIFICACION
        cmd /c where php    -> C:\tools\php84\php.exe   (DEBE ser el 1º)
        cmd /c where psql   -> C:\Program Files\PostgreSQL\17\bin\psql.exe
        composer --version  -> debe anunciar "PHP version 8.4.26
                               (C:\tools\php84\php.exe)", no el de XAMPP

 # 7. PASOS DE INSTALACION, EN ORDEN
################################################################################

  [S1]  Instalar VC++ 2015-2022 Redistributable x64 (vc_redist.x64.exe,
        https://aka.ms/vs/17/release/vc_redist.x64.exe) con /install /quiet.
        Si devuelve 1638 = ya hay otra version instalada -> OK, seguir.

  [S2]  Descargar php-8.4.26-nts-Win32-vs17-x64.zip desde
        https://windows.php.net/downloads/releases/ y extraer a C:\tools\php84.

  [S3]  Crear C:\tools\php84\php.ini desde php.ini-development:
        - extension_dir = "ext"  (una sola linea)
        - extension=pdo_pgsql, extension=pgsql, extension=curl,
          extension=mbstring, extension=intl, extension=zip,
          extension=fileinfo, extension=gd, extension=sodium, extension=soap
        - NO poner extension= para bcmath/tokenizer/dom/xml (van en php8.dll)
        - zend_extension = opcache
        Verificar: php -v sin warnings, php -m con pdo_pgsql y bcmath.

  [S4]  Instalar PostgreSQL 17.6 con el ASISTENTE GRAFICO (nunca desatendido),
        puerto 5432, locale Spanish_Bolivia.1252, servicio Automatic.
        Incluye pgAdmin 4 (sustituye a DBeaver).

  [S5]  Instalar Composer 2.9.7 (https://getcomposer.org/download/).

  [S6]  Instalar Node.js 24 LTS y Git 2.x.

  [S7]  Ajustar el PATH de SISTEMA (seccion 3): php84 y PostgreSQL\bin ANTES
        de C:\xampp\php. Respaldo previo. Abrir terminal NUEVA despues.

  [S8]  Crear rol y bases (seccion 4.3). Verificar $LASTEXITCODE = 0.

  [S9]  Clonar el repo y montar el backend:
        git clone <repo> epcoro && cd epcoro\epcoro-api
        composer install
        copy .env.example .env
        php artisan key:generate
        (editar .env: DB_PASSWORD=epcoro_secret)
        php artisan migrate --seed --force
        php artisan test          -> debe dar tests en verde

  [S10] Montar el frontend:
        cd ..\epcoro-web
        npm install
        npm run build             -> vue-tsc + vite build sin errores

  [S11] VS Code: abrir epcoro.code-workspace e instalar las extensiones
        recomendadas: PHP Intelephense, Laravel Blade, EditorConfig,
        Prettier, ESLint, Vue - Official (Volar), Tailwind CSS IntelliSense,
        DotENV, Duplicate.
